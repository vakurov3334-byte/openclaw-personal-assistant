Кто использует приложение

OpenClaw Personal Assistant — личная установка помощника владельца аккаунта. Контакт по вопросам доступа и данных: vakurov3334@gmail.com.

Какие данные доступны

После согласия в Google OAuth приложение получает доступ к адресу Google-аккаунта, метаданным и содержимому файлов Google Drive и документов Google Docs в пределах выданных разрешений. Доступ Drive позволяет читать, создавать и изменять файлы. Для текущей настройки подключаются только Drive и Docs; доступ к Gmail, контактам и календарю не запрашивается.

Для чего используются данные

Данные нужны для выполнения поручений владельца: поиска и чтения документов, подготовки ответов, загрузки и организации файлов, редактирования документов и контроля проектных обязательств. Разрешение OAuth само по себе не является поручением изменять или публиковать файлы.

Где обрабатываются и хранятся данные

Авторизацию gogcli хранит локально на Mac через macOS Keychain. Полученные материалы и результаты работы могут сохраняться в локальных файлах и журналах OpenClaw/Codex, а также в документах, выбранных владельцем. Для подготовки ответов выбранные фрагменты документов и поручения могут передаваться сервисам OpenAI через используемую владельцем среду Codex. К этой обработке применяются настройки аккаунта и условия соответствующего сервиса.

Google-данные не продаются и не используются приложением для рекламы. Они передаются только в объёме, необходимом для работы функций помощника и выполнения поручений владельца. Приложение не использует Google-данные для создания или обучения собственной общей модели.

Использование и передача информации, полученной через Google APIs, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отключить доступ и удалить данные

Владелец может отозвать разрешение на странице подключений Google-аккаунта и отключить интеграцию в локальном OpenClaw. Отзыв прекращает дальнейший доступ, но не удаляет уже сохранённые копии. Локальные материалы и журналы удаляет владелец; сохранённые файлы Google Drive остаются под его управлением. Данные в сторонних сервисах управляются через их настройки и процедуры удаления. Автоматический срок удаления локальных материалов этой настройкой не задан.

Данные посетителей этой страницы

На странице нет форм, аналитики и сторонних скриптов. Статические страницы размещаются на GitHub Pages. GitHub может сохранять технические данные посещений, включая IP-адреса, для безопасности в соответствии со своей политикой конфиденциальности. Через этот сайт не передаются OAuth-токены или файлы Google Drive.
